# random-password

A simple random password generator.

Built with Vue 3, Vite, and TypeScript. The upgrade from Vue 2 is in progress
(see issues labeled `vue3-upgrade`). Code that hasn't been ported yet lives in `legacy/`.

## Requirements

Node.js 22.18+ or 24.12+

## Commands

```sh
npm install        # install dependencies
npm run dev        # start the dev server with hot reload
npm run build      # type-check and build for production into dist/
npm run preview    # serve the production build locally
npm run type-check # check TypeScript types, including .vue files
npm run lint       # check code with ESLint (npm run lint:fix to auto-fix)
npm run format     # format src/ with Prettier
```
